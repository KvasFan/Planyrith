This preview gathers six milestones of work since alpha.2: 3D printing,
realistic rendering, new modeling tools, many more file formats, parametric
components, working together over a network, and a touch layout. It is still a
pre-release: please report anything that looks wrong.

### Highlights

- **3D printing:** Tools › Solids › Check for 3D Printing lists every object with
  its size and problems, marks open edges in red and repairs what it can; 3MF
  import and export, with one file per object or objects resting on the plate.
- **Realistic images:** a realistic style (sky light, ambient occlusion, soft
  shadows, roughness and metalness), path-traced final images (File › Export ›
  Rendered Image…, `planyrith render --path-traced`, `--gpu` on the graphics
  card) and a live Path-Traced Preview in the View menu.
- **Modeling:** round or chamfer edges, thicken surfaces into solids, Bézier
  curves, loft between profiles, parametric components (a cabinet that follows
  its width), and Camera › Match Photo… to model over a photograph.
- **Formats:** COLLADA, FBX, PLY and IFC both ways; USD/USDZ export.
- **Working together:** several people can edit one document through
  `planyrith serve`, each with their own selection, seeing the others; network
  connections are encrypted with the server's token (File › Work Together…).
- **Extensions:** plugins can be WebAssembly modules as well as scripts.
- **Interface:** Italian translation, a touch layout for tablets, interface
  size, color-blind safe axes, high-contrast snap marks, preferences and layout
  presets.

### Fixes

- Meshes whose parts overlap in one plane (cut-out figures, decals) no longer
  lose those parts on import.
- Results no longer change when a document is saved and reopened between
  edits; long randomized test runs (100 000 edit sequences) now pass.
- Path-traced images show reversed faces with their front material; zoom
  extents ignores hidden geometry; bounds of turned components are exact.

### Known limits

- **No macOS build in this preview:** the macOS disk image is built on GitHub's
  macOS machines, which are unavailable to this project at the moment. Build it
  on a Mac with the commands in the install notes.
- The Windows programs in this preview are built with the GNU toolchain instead
  of the usual MSVC one, and were tried under Wine rather than Windows; please
  report any problem on Windows.
- Files from releases 2023 and 2024 are untested; files saved here have only
  been read back by Planyrith.

### Install

| Platform | Download |
|---|---|
| Windows 10/11 x64 | `Planyrith-0.11.0-alpha.4-windows-x86_64-setup.exe` |
| Windows 10/11 x64, managed installs | `Planyrith-0.11.0-alpha.4-windows-x86_64.msi` |
| Windows portable | `planyrith-0.11.0-alpha.4-windows-x86_64-portable.zip` |
| Linux portable | `Planyrith-0.11.0-alpha.4-x86_64.AppImage` |
| Linux with Flatpak | `Planyrith-0.11.0-alpha.4-x86_64.flatpak` |
| Debian / Ubuntu | `planyrith_0.11.0-alpha.4_amd64.deb` |
| Arch Linux | `planyrith-0.11.0alpha4-1-x86_64.pkg.tar.zst` |
| Linux archive | `planyrith-0.11.0-alpha.4-linux-x86_64.tar.gz` |

Run the Windows setup (or `msiexec /i Planyrith-*.msi`), or extract the portable
ZIP and launch `planyrith-gui.exe`. Linux: `chmod +x *.AppImage` then run it;
use `--appimage-extract-and-run` if FUSE is unavailable. Install Debian packages
with `sudo apt install ./planyrith_*_amd64.deb`, Arch packages with
`sudo pacman -U ./planyrith-*-x86_64.pkg.tar.zst`, and the Flatpak with
`flatpak install --user Planyrith-*.flatpak`.

### Notes

This is an **alpha prerelease**. The Windows installers are unsigned. Linux
requires x86_64, glibc 2.35 or newer and working graphics drivers.

The applications are MIT OR Apache-2.0. The optional SKP/SKB helper runs as a
separate GPL-3.0-only process; the Windows setup allows omitting it. Complete
locked Cargo source and the AppImage runtime sources are attached.
`SHA256SUMS` covers all attached downloads.
