This preview opens many more real SKP models and keeps more of them when you
save. If a model failed to open in the previous preview, try it again.

### Highlights

- Opens large models that stopped with an error before: tags with custom dashed
  line styles, textures embedded as Photoshop, TIFF, GIF or Targa images, and
  faces with unusual outlines. A single unreadable image no longer stops a model
  from opening; its material keeps its color and you get a notice.
- SKP models now open from their saved view. It was being lost for every model.
- The window keeps responding while a document opens, with a progress dialog.
- Large models open about three times faster the first time, and saving a large
  `.plyr` takes seconds: a 160 MB model went from about 18 s to 2 s.
- Rename a component with `component-rename`, or double-click its name in the
  Components panel.
- Saving back to SKP keeps texture tints, scene transition times, slide settings,
  and guide and section plane attributes. A face or image that cannot be
  represented exactly no longer stops the save.

### Fixes

- Models from 2013–2016, 2019 and 2020 no longer open in X-ray on a transparent
  background. Their saved styles are not imported yet: they use the default
  style, with a notice. Working copies saved earlier keep the old style, so
  reopen the original file to get the correct one.
- Radial dimensions on curves away from the origin attach at the right point.
- Styles no longer multiply each time a model with scenes is saved and reopened.
- Repair no longer removes retained stroke images.
- Files older than 2013 are refused with a clear message.

### Known limits

- Files saved here have only been read back by Planyrith. Please report anything
  that looks wrong when you open them in other applications.
- Files from releases 2023 and 2024 are untested, as no sample was available.
- Tag line styles are read but not written back to SKP.

### Install

| Platform | Download |
|---|---|
| Windows 10/11 x64 | `Planyrith-0.11.0-alpha.3-windows-x86_64-setup.exe` |
| Windows portable | `planyrith-0.11.0-alpha.3-windows-x86_64-portable.zip` |
| Linux portable | `Planyrith-0.11.0-alpha.3-x86_64.AppImage` |
| Debian / Ubuntu | `planyrith_0.11.0-alpha.3_amd64.deb` |
| Arch Linux | `planyrith-0.11.0alpha3-1-x86_64.pkg.tar.zst` |
| Linux archive | `planyrith-0.11.0-alpha.3-linux-x86_64.tar.gz` |

Run the Windows setup, or extract the portable ZIP and launch
`planyrith-gui.exe`. Linux: `chmod +x *.AppImage` then run it; use
`--appimage-extract-and-run` if FUSE is unavailable. Install Debian packages
with `sudo apt install ./planyrith_*_amd64.deb`, or Arch packages with
`sudo pacman -U ./planyrith-*-x86_64.pkg.tar.zst`.

### Notes

This is an **alpha prerelease**. Complete SKP visual/edited-output fidelity
and certification for every version remain in progress. Historical imports
cover 2013 onward; edited writers are 2017 and 2026. Keep native working
copies and review conversion notices. The Windows installer is unsigned.
Linux requires x86_64, glibc 2.35 or newer and working graphics drivers.

The applications are MIT OR Apache-2.0. The optional SKP/SKB helper runs as a
separate GPL-3.0-only process; Windows setup allows omitting it. Complete locked
Cargo source and separate AppImage runtime/relink sources are attached.
`SHA256SUMS` covers all attached downloads. Installer and extracted-package
smoke tests, plus CI for the packaged revision, gate publication.
