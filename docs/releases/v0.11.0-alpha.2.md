Planyrith now has ready-to-install desktop packages and a refreshed project
page with current application screenshots.

### Highlights

- Open historical SKP models from 2013 onward and SKB backups directly from
  the desktop, CLI or RPC. New regressions cover 2013–2016 geometry and nesting.
- Keep `.plyr` as the default first save, with protection against accidentally
  replacing an existing native working copy.
- Windows setup with Start menu integration, optional native file association
  and separate format module; AppImage, Debian and Arch packages for Linux.
- GUI and CLI in every package, including headless rendering, scripting,
  extensions, solid tools and scaled Sheets/PDF export.

### Fixes

- Recover classic model colors, trailing definitions, bitmap assets and complex
  surfaces. Conversion errors report the actual failure instead of declaring
  a valid source container corrupt.
- Preserve explicit foreign save choices for desktop and attached RPC sessions.
- Retain original source bytes through native saves: an unchanged foreign save
  restores the original file and version exactly.

### Install

| Platform | Download |
|---|---|
| Windows 10/11 x64 | `Planyrith-0.11.0-alpha.2-windows-x86_64-setup.exe` |
| Windows portable | `planyrith-0.11.0-alpha.2-windows-x86_64-portable.zip` |
| Linux portable | `Planyrith-0.11.0-alpha.2-x86_64.AppImage` |
| Debian / Ubuntu | `planyrith_0.11.0-alpha.2_amd64.deb` |
| Arch Linux | `planyrith-0.11.0alpha2-1-x86_64.pkg.tar.zst` |
| Linux archive | `planyrith-0.11.0-alpha.2-linux-x86_64.tar.gz` |

Run the Windows setup, or extract the portable ZIP and launch
`planyrith-gui.exe`. Linux: `chmod +x *.AppImage` then run it; use
`--appimage-extract-and-run` if FUSE is unavailable. Install Debian packages
with `sudo apt install ./planyrith_*_amd64.deb`, or Arch packages with
`sudo pacman -U ./planyrith-*-x86_64.pkg.tar.zst`.

### Notes

This is an **alpha prerelease**. Complete SKP visual/edited-output fidelity
and certification for every version remain in progress. Historical imports
cover 2013 onward; edited writers are 2017 and 2026. Keep native working
copies and review conversion notices. The Windows installer is unsigned.
Linux requires x86_64, glibc 2.35 or newer and working graphics drivers.

The applications are MIT OR Apache-2.0. The optional SKP/SKB helper runs as a
separate GPL-3.0-only process; Windows setup allows omitting it. Complete locked
Cargo source and separate AppImage runtime/relink sources are attached.
`SHA256SUMS` covers all attached downloads. Installer and extracted-package
smoke tests, plus CI for the packaged revision, gate publication.
