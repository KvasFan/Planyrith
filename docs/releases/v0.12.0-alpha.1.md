This preview turns Planyrith into an engineering modeler as well: constrained
sketches, a feature history, assemblies, engineering drawings, sheet metal,
simulation and more ways to exchange product data. It is still a pre-release:
please report anything that looks wrong.

### Highlights

- **Constrained sketches:** constraints and driving dimensions on lines, arcs
  and circles (radius, equal radii, concentric, tangent, point on curve), kept
  by a solver that shows the freedom left. Tools › Constraints….
- **Feature history:** parametric parts rebuilt from an ordered list of
  features, with formulas, suppression, reordering, rollback and
  configurations. Picks recorded by a feature still find their faces after
  earlier features change. Tools › Features….
- **Solid features:** holes (plain, clearance, tapped, counterbore,
  countersink), shell, draft, dome, rib, and splitting a solid by a plane or a
  surface. Mirror, Revolve and Pattern work as viewport tools.
- **Assemblies:** mates between components kept by a solver, exploded views,
  bill of materials, motion studies, collision checks while moving, and Move
  can stop at first contact.
- **Engineering drawings:** projected, auxiliary, section, detail and broken
  views that follow the model; tolerance frames, datums, surface texture and
  weld symbols; balloons; ISO and ANSI sheet formats.
- **Fabrication:** sheet metal with stacked flanges (returns, hems,
  Z-bends), corner reliefs and flat patterns; frame members with mitered
  joints; molds with stepped parting surfaces and undercut detection; pipe
  routing with elbows, tees and reducers.
- **Simulation:** static stress, natural frequencies and heat conduction
  (with convection), on meshes that follow curved faces. Tools › Simulation….
- **Surfaces and analysis:** fill, extend, trim (by a plane or another
  surface) and knit surfaces; curvature, zebra, draft and wall-thickness
  analysis.
- **Product data and exchange:** part numbers and properties, revisions,
  standard parts (ISO bolts, nuts, washers, bearings); STEP with product
  structure and annotations; IGES both ways, with curved surfaces and
  components; USD and USDZ import.
- **Working together:** undo only your own changes in a shared session, and
  join a session from a browser.

### Fixes

- Mirrored solids no longer fail to intersect.
- Move previews and typed values honor the Copy option.
- Simulation binds the chosen body independently of the face selection, and
  its results are placed correctly.

### Known limits

- **No macOS build in this preview:** the macOS disk image needs Apple's
  hardware, which this project's builds cannot use at the moment. Build it on
  a Mac with the commands in the install notes.
- The Windows programs are built with the GNU toolchain instead of the usual
  MSVC one, and were tested under Wine rather than Windows; please report any
  problem on Windows.
- Files from releases 2023 and 2024 of the SKP format are untested; files
  saved here have only been read back by Planyrith.

### Install

| Platform | Download |
|---|---|
| Windows 10/11 x64 | `Planyrith-0.12.0-alpha.1-windows-x86_64-setup.exe` |
| Windows 10/11 x64, managed installs | `Planyrith-0.12.0-alpha.1-windows-x86_64.msi` |
| Windows portable | `planyrith-0.12.0-alpha.1-windows-x86_64-portable.zip` |
| Linux portable | `Planyrith-0.12.0-alpha.1-x86_64.AppImage` |
| Linux with Flatpak | `Planyrith-0.12.0-alpha.1-x86_64.flatpak` |
| Debian / Ubuntu | `planyrith_0.12.0-alpha.1_amd64.deb` |
| Arch Linux | `planyrith-0.12.0alpha1-1-x86_64.pkg.tar.zst` |
| Linux archive | `planyrith-0.12.0-alpha.1-linux-x86_64.tar.gz` |

Run the Windows setup (or `msiexec /i Planyrith-*.msi`), or extract the portable
ZIP and launch `planyrith-gui.exe`. Linux: `chmod +x *.AppImage` then run it;
use `--appimage-extract-and-run` if FUSE is unavailable. Install Debian packages
with `sudo apt install ./planyrith_*_amd64.deb`, Arch packages with
`sudo pacman -U ./planyrith-*-x86_64.pkg.tar.zst`, and the Flatpak with
`flatpak install --user Planyrith-*.flatpak`.

### Notes

This is an **alpha prerelease**. The Windows installers are unsigned. Linux
requires x86_64, glibc 2.35 or newer and working graphics drivers. Documents
are still `.plyr` format version 1, so files from 0.11 open unchanged.

The applications are MIT OR Apache-2.0. The optional SKP/SKB helper runs as a
separate GPL-3.0-only process; the Windows setup allows omitting it. Complete
locked Cargo source and the AppImage runtime sources are attached.
`SHA256SUMS` covers all attached downloads.
