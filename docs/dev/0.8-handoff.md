# 0.8 release handoff

Updated 2026-10-28 after the user resumed the paused session. This replaces the
pause audit; its outstanding implementation items have been resolved.

## Authorized release procedure

Complete 0.8.0, create local commits, push once at the end, wait for green CI,
then stop. Do not create `v0.8.0` before the user has tried the release.

## Delivered

- Six solid operations, coplanar clipping/merging, deterministic ray parity and
  a numerical B-rep retry; source face appearance and boundary flags retained.
- Minimum-rotation Sweep with mitered corners, closed-path twist correction,
  consumed path faces and hidden triangulation for nonplanar quads.
- Intersect Faces and Soften/Smooth. All new geometry tools have registry/CLI
  commands, canonical goldens, undo byte checks and fuzz-sequence coverage.
- STEP import/export with exact planar boundary round-trips within tolerance,
  holes and associated cavity shells. Fixtures and their Rust generator are
  checked in. Assemblies requiring placement interpretation are rejected.
- Rhai command bindings, units, queries, selection/context, grouping, attributes,
  output/progress capture, cancellation and execution/data limits. Scripts are
  previewed and replayed atomically as one undo step.
- CLI scripts, batch script lines, RPC script evaluation and plugin
  install/check/list. Three bundled examples: stairs, cabinet and CSV points.
- Validated plugin archives, callback signatures, constrained recursive schemas,
  forms with units, menus, optional toolbars and panels; Extension Manager and
  Console. Native attach executes commands/history/save on an authenticated
  local server and refreshes the native document snapshot.
- Workspace version 0.8.0, release notes and normative Decisions updated.

The manifest supports only `ui_forms` as an extension capability. Filesystem,
network, time and randomness access are refused. Persistent event callbacks,
startup scripts, dynamic UI prompts and custom format registration remain
reserved; see docs/10 Decisions. Interpreter container/string/variable limits
and command/output accounting do not constitute a process-wide heap quota.
Native geometry deadline checks happen between calls. Browser socket attach
is outside this release.

## Dependencies

Rhai/TOML and the truck family are optional core features, enabled by the
frontends. The published Rust source of truck-shapeops is patched locally only
to disable the VTK dependency path (which introduces a C backend), with source,
license and change provenance under `vendor/truck-shapeops`. Three narrowly
scoped unmaintained-dependency advisories are documented in docs/02; no known
vulnerability is ignored. `cargo deny check` passes.

## Acceptance and validation

Passed locally:

- Twelve-face cube union and volume identity, coplanar/touching/contained cases,
  cylinder through a slab, B-rep fallback and randomized box properties.
- Circular profile around a closed square, ordinary closed-path faces and
  nonplanar sweeps; byte-exact undo/redo of geometry and scripting/attributes.
- Planar STEP fixtures with holes and cavities, stable writer output and
  malformed input handling.
- CLI scripts/batches/RPC/install persistence and all three example plugins.
- Identical canonical stairs exports through CLI and GUI Session; real local
  server attach, authentication, script, undo/redo, save and reopen.
- Full workspace tests, native/wasm clippy with warnings denied, documentation
  with warnings denied, formatting and dependency/license checks.

The release web bundle is 5,160,320 bytes with brotli, below 12 MiB. Browser
storage and classroom acceptance both pass in headless Chrome. Browser tests
disable debug sections to reduce wasm-bindgen's peak memory while retaining
assertions. Verify the CI run for the final pushed head before stopping.
