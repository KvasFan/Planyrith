This preview fixes what a test of every tool found in 0.13.0-alpha.1 and makes natural
frequency analysis much faster. It also contains everything 0.13.0-alpha.1 added: DWG import,
3DS, binary USD, FBX 6, IGES solids, STEP dimensions as data, side flanges, inner circle
tangency and freeform mold partings. It is still a pre-release: please report anything that
looks wrong.

### Fixes

- **3D text:** filled letters such as A, P, Q, R, a, e, 4 and & made an invalid model, because
  the bundled font draws them from overlapping outlines; they are now filled as the font fills
  them and extrude into closed solids. Outlined letters no longer show the overlapping lines.
- **Freehand:** a stroke that ran back over itself could save a file that would not open
  again. Such files now open.
- **Push/Pull:** pulling a face with a hole could lose the top for some hole positions,
  leaving an open shell.
- **IGES:** models with components touching inside another component (a cabinet's sides and
  shelves) can be imported back; overlapping parts come in as separate groups with a warning.
- **Simulation:** a mesh size of zero is refused instead of stopping the program.

### Faster

- **Natural frequencies** with the default mesh take about a second for a small part instead
  of a minute, with the same results.

### Known limits

- **No macOS build in this preview** (see the install notes to build it on a Mac).
- Details smaller than 0.01 mm are below the modeling kernel's resolution: Push/Pull near them
  may leave an open shell, which it reports.
- DWG drawings saved in release 2007 or before 2000 are refused; save them in another
  release. DWG text, dimensions and hatches are not brought in, as with DXF.
- The Windows programs are built with the GNU toolchain and were tested under Wine rather
  than Windows; please report any problem on Windows.
- Files from releases 2023 and 2024 of the SKP format are untested.

### Install

| Platform | Download |
|---|---|
| Windows 10/11 x64 | `Planyrith-0.13.0-alpha.2-windows-x86_64-setup.exe` |
| Windows 10/11 x64, managed installs | `Planyrith-0.13.0-alpha.2-windows-x86_64.msi` |
| Windows portable | `planyrith-0.13.0-alpha.2-windows-x86_64-portable.zip` |
| Linux portable | `Planyrith-0.13.0-alpha.2-x86_64.AppImage` |
| Linux with Flatpak | `Planyrith-0.13.0-alpha.2-x86_64.flatpak` |
| Debian / Ubuntu | `planyrith_0.13.0-alpha.2_amd64.deb` |
| Arch Linux | `planyrith-0.13.0alpha2-1-x86_64.pkg.tar.zst` |
| Linux archive | `planyrith-0.13.0-alpha.2-linux-x86_64.tar.gz` |

Run the Windows setup (or `msiexec /i Planyrith-*.msi`), or extract the portable
ZIP and launch `planyrith-gui.exe`. Linux: `chmod +x *.AppImage` then run it;
use `--appimage-extract-and-run` if FUSE is unavailable. Install Debian packages
with `sudo apt install ./planyrith_*_amd64.deb`, Arch packages with
`sudo pacman -U ./planyrith-*-x86_64.pkg.tar.zst`, and the Flatpak with
`flatpak install --user Planyrith-*.flatpak`.

### Notes

This is an **alpha prerelease**. The Windows installers are unsigned. Linux
requires x86_64, glibc 2.35 or newer and working graphics drivers. Documents
are still `.plyr` format version 1, so files from 0.12 open unchanged.

The applications are MIT OR Apache-2.0. The optional SKP/SKB helper runs as a
separate GPL-3.0-only process; the Windows setup allows omitting it. Complete
locked Cargo source and the AppImage runtime sources are attached.
`SHA256SUMS` covers all attached downloads.
