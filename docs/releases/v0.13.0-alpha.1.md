This preview completes the limits left in the engineering milestones and brings in more of
the formats other tools save. It is still a pre-release: please report anything that looks
wrong.

### Highlights

- **DWG import:** drawings saved in releases 2000, 2004, 2010, 2013 and 2018 come in like
  DXF: layers as tags, blocks as components, lines, arcs, circles, ellipses, splines,
  polylines, polyface meshes, 3D faces and solids.
- **More formats:** 3DS import and export; binary USD layers (`.usdc`, and inside `.usdz`);
  FBX 6 files, text and binary.
- **IGES solids:** bodies saved as B-rep solids come in whole, curved faces included, and
  `export --solids` (the IGES export in the application) writes closed shells as solids.
- **STEP dimensions as data:** dimensions travel with their nominal value and plus/minus
  tolerance; dimensions and geometric tolerances that other tools give only as data come in
  as notes where they apply.
- **Sheet metal:** tabs bent from the sides of a flange (Fabrication › Bend Start Side, Bend
  End Side).
- **Molds:** divide a mold along any surface you model, and let side actions free the
  undercuts that can slide out sideways (Molds › Parting surface group, Side actions).
- **Constraints:** a circle can touch another from inside (give the inner one fewer segments).

### Fixes

- Drawings with long curved outlines (revision clouds, contour lines) import in seconds
  instead of minutes.
- Curved IGES faces no longer leave gaps along finely sampled edges.

### Known limits

- **No macOS build in this preview** (see the install notes to build it on a Mac).
- DWG drawings saved in release 2007 or before 2000 are refused; save them in another
  release. DWG text, dimensions and hatches are not brought in, as with DXF.
- The Windows programs are built with the GNU toolchain and were tested under Wine rather
  than Windows; please report any problem on Windows.
- Files from releases 2023 and 2024 of the SKP format are untested.

### Install

| Platform | Download |
|---|---|
| Windows 10/11 x64 | `Planyrith-0.13.0-alpha.1-windows-x86_64-setup.exe` |
| Windows 10/11 x64, managed installs | `Planyrith-0.13.0-alpha.1-windows-x86_64.msi` |
| Windows portable | `planyrith-0.13.0-alpha.1-windows-x86_64-portable.zip` |
| Linux portable | `Planyrith-0.13.0-alpha.1-x86_64.AppImage` |
| Linux with Flatpak | `Planyrith-0.13.0-alpha.1-x86_64.flatpak` |
| Debian / Ubuntu | `planyrith_0.13.0-alpha.1_amd64.deb` |
| Arch Linux | `planyrith-0.13.0alpha1-1-x86_64.pkg.tar.zst` |
| Linux archive | `planyrith-0.13.0-alpha.1-linux-x86_64.tar.gz` |

Run the Windows setup (or `msiexec /i Planyrith-*.msi`), or extract the portable
ZIP and launch `planyrith-gui.exe`. Linux: `chmod +x *.AppImage` then run it;
use `--appimage-extract-and-run` if FUSE is unavailable. Install Debian packages
with `sudo apt install ./planyrith_*_amd64.deb`, Arch packages with
`sudo pacman -U ./planyrith-*-x86_64.pkg.tar.zst`, and the Flatpak with
`flatpak install --user Planyrith-*.flatpak`.

### Notes

This is an **alpha prerelease**. The Windows installers are unsigned. Linux
requires x86_64, glibc 2.35 or newer and working graphics drivers. Documents
are still `.plyr` format version 1, so files from 0.12 open unchanged.

The applications are MIT OR Apache-2.0. The optional SKP/SKB helper runs as a
separate GPL-3.0-only process; the Windows setup allows omitting it. Complete
locked Cargo source and the AppImage runtime sources are attached.
`SHA256SUMS` covers all attached downloads.
